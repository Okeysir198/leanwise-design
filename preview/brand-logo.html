The gradient stops above are literal hexes, and that is deliberate. CSS custom properties do not cascade into an SVG loaded through <img>, so the shipped logo-mark.svg must carry real values — which makes the SVG a second home for a brand colour. assets/build-logo.py generates them from tokens.css and bin/lw-contrast-check.mjs fails if the two ever disagree; lw-token-lint cannot see inside a .svg, so that gate is the only thing guarding it. The card mirrors the asset verbatim rather than tokenising it, so what you review here is exactly what ships. Every non-artwork colour on this card is tokenised.

currentColor only works inlined. Through <img> it resolves against the SVG's own root and paints black — use CSS mask over a background instead.
