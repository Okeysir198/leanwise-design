Type scale

Geist, self-hosted, with Vietnamese subsets. Eight roles — four headings, three text sizes, one eyebrow. The numbers on the right are read from the rendered specimen, not typed in, so this card cannot drift from the tokens.

The four heading roles are fluid — clamp() against the viewport, so a hero on a phone is not a desktop hero scaled down. Body, sm and eyebrow are fixed: reading size is not a function of window width.
