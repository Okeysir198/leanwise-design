Elevation

Five tiers, navy-tinted so shadows read as depth on a light page rather than as soot. Each tile applies the token itself, so the specimen cannot drift from the scale.

xs is a 1px ground line — the faintest lift, separating a surface from the page without casting. xl is a floating popover/command-menu shadow.

On dark these re-point to black. A navy-tinted shadow is invisible on a navy ground, so the dark theme swaps them and leans on the hairline border for elevation instead. Flip your system theme and this card follows.
