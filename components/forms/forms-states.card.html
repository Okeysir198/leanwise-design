Controls — every state

The focus column is the shipped focus state, not a repaint. A card cannot hold real focus in seven cells at once, so each one carries data-focus-demo — a review hook listed alongside :focus-visible in the same declaration block, so the specimen cannot drift from the control. On a control with a neutral ground the ring is a solid 2px brand band via box-shadow: v1.1 replaced a 3px halo at 30% alpha, which had no defined edge and so read as a glow rather than as the brand colour — and being translucent it mixed with whatever sat behind it, so one ring looked like a different colour per surface. v1.1 also fixed the case behind this column: clicking a <select> does not match :focus-visible in Chromium, so a mouse-focused control fell through to the browser's outline — the UA's colour, not the brand's.

Brand-filled controls take a detached ring instead, and this is the rule to copy: a checked switch, a checked checkbox or radio, and the filled buttons use outline: 2px solid with outline-offset: 2px, not a band. A brand ring flush against a brand fill is 1:1 against it — it reads as the control getting 2px bigger, not as focus. The gap has to be transparent so it shows whichever ground the control actually sits on, which is why this is an outline and not a second box-shadow stop: a transparent shadow layer paints nothing, it does not mask the layer beneath, and a gap painted from --lw-bg would show a white sliver on every bg-subtle surface. Two mechanisms, one look — a 2px brand ring either way; only the brand-filled cases need the gap.

Invalid is an attribute, not a class. Every cell in the invalid column carries aria-invalid="true" and nothing else — the colour is bound to the attribute a screen reader reads, so the visual and the announced state cannot desync. Inspect one and there is no .error to find.

Disabled is the only column allowed to fail contrast, and it must still look disabled on navy — which is why it is painted from --lw-bg-muted / --lw-fg-faint, roles that every dark scope re-points, rather than from a fixed grey tier.

Segmented takes two to four mutually exclusive options — and it is the same control the theme toggle renders, because a two-or-three-state exclusive choice is one control, not two. v1.0 deleted the second implementation of it.

Every control here reaches 44px on a coarse pointer without changing its desktop height, so density and the touch minimum are not forced to be the same number. The label is part of the Switch and Checkbox, so the text is a hit target too.
