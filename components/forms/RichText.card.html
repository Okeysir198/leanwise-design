RichText

The chrome is the system's; the engine is not. A toolbar and a prose surface on the type scale — swap TipTap or ProseMirror in underneath and the toolbar does not change, which is the only way a rich-text editor stops being a fork of the design system. The default surface is contenteditable + execCommand: honest about what it is, fine for a comment box, not for a document.

The toolbar is data, not markup, so a product drops a control by filtering an array. Each button is a real control with a label and aria-pressed, and the surface is a role="textbox" aria-multiline — a bare contenteditable div announces nothing.
