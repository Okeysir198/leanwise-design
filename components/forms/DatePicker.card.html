Date, upload, progress

The presets are the point of a range picker. "Last 7 days" is what a user wants nine times out of ten, and making them build it from two clicks on a grid is the difference between a control and a chore. The grid is real buttons with a roving tabindex — a date grid is only usable by keyboard if each cell can hold focus. Month and weekday names come from Intl, so it localises with the browser.

The dropzone is a <label> wrapping a real file input, so the click target, the keyboard path and the accessible name are the platform's. Drag is the enhancement. The drag counter is not decoration: dragleave fires when the pointer crosses onto a child, so a boolean flickers off every time the cursor passes the icon.
