Command palette

A dialog, not a popover. It is modal, it takes the whole keyboard, and the page behind it should be inert — so it is the native element with the platform's focus trap, for the same reason Dialog is.

It does not bind ⌘K. A component that installs a global key handler fights the host app for the shortcut and cannot be turned off on the one screen where ⌘K means something else. Bind it where you mount it. Matching is a scored subsequence, not a substring: "opdb" finds "Open database", and an early contiguous match ranks above a scattered one — a palette that returns the right row ninth is one people stop using.
