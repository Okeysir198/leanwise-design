Agent surfaces

AgentTrace says a step ran; ToolCall says what it did. Pair them — the trace is the spine, the calls are the evidence hanging off it. Collapsed by default, because an argument blob is something a user opens when the answer looks wrong, not something to read every turn.

The diff gutter carries the sign as well as the ground, so it reads in greyscale and to a colour-blind reader, and the diff tokens are grounds — the text on top stays --lw-fg, because green-on-green is unreadable at exactly the moment it matters.

One system rule these encode: an AI surface is never the only path to an outcome. Every artifact has a manual editor and a revert; every rating has a correction path, because a number nobody can act on is not feedback.
