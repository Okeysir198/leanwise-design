Overlays

Dialog is the native <dialog>. Focus trap, Esc-to-close and background inertness are the platform's job here rather than two hundred lines of ours — and the platform's version is the one screen readers already understand. Nothing else in this system re-implements a browser primitive.

A drawer is a modal that enters from an edge, not a different kind of thing — so it is the same native element, with the same trap: the UA hides a closed <dialog>, and an unconditional display on the class outranks that and paints closed panels in flow.

Toast carries a mono status word, not only coloured ink, and errors use role="alert" while everything else uses role="status": an error should interrupt, a confirmation should not. Tooltip is for hints only — it does not exist on touch.
