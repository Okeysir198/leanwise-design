Overlays

Dialog is Radix Dialog, portal-rendered into the overlay layer. The focus trap, Esc, the scroll lock, a click on the scrim and aria-hidden on the rest of the page are Radix's; what is ours is where it lands: an .lw-layer-modal inside the nearest OverlayProvider — or document.body, mirroring the opener's theme scope, which is why the panel opened from the dark pane paints dark. The native <dialog> it replaces lived in the browser's top layer, above every container, so it could not inherit a tenant's brand and a Menu opened inside it landed under its own backdrop.

A drawer is a modal that enters from an edge, not a different kind of thing — so it is the same shell, the same layer and the same scrim (.lw-backdrop, one rule for all three), with only the panel's geometry to itself. data-side is logical: start, end, bottom.

Toast carries a mono status word, not only coloured ink, and errors use role="alert" while everything else uses role="status": an error should interrupt, a confirmation should not. Tooltip is for hints only — it does not exist on touch.
