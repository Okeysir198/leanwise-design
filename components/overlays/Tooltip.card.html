Tooltip

Hints only. A tooltip does not exist on touch, so anything a user needs — a label, an error, an instruction — must not live here. It is for the shortcut key next to a button that already has a name.

Since v2.0 it is read, not only seen. Until now the hint was a data-tip attribute painted by ::after: visible to a sighted mouse user and to nobody else. The Radix content carries role="tooltip" and the trigger gains aria-describedby, so a screen reader announces the hint with the button. It portals into the OverlayProvider's layer and mirrors the trigger's band scope, so a tooltip opened from a dark band paints the same navy-on-white pair it does everywhere — both are tiers, not roles.
