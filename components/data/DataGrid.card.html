DataGrid

Not an extension of Table. A grid owns its own scroll box, a sticky header, resizable and pinnable columns and optional windowing — merging the two would make every static table pay for machinery it never uses. Reach for Table first; reach for this when the data outgrows it.

The selection bar replaces the toolbar rather than stacking under it — two rows of controls where one was is how a table jumps a row height on every click. A pinned cell carries its own background, because sticky positions a box, it does not make it opaque. Pinned columns stack, so each offset is the sum of the widths before it.
