Button — every state

This card is live — hover a cell, and tab through a row. There is no fake focus column: the ring is :focus-visible only, so a painted imitation of it would be the second implementation this package spent v1.0 deleting. Tab into the dark pane and the ring switches to the brand-400 tier, because the 500 ring disappears into navy. The filled variants take outline-offset rather than a band — a brand ring flush against a brand fill is 1:1 against it, so it would read as the button getting 2px bigger.

Loading keeps the button focusable and holds its width, so the layout does not jump and the keyboard does not lose its place. Disabled is the one state allowed to fail contrast — it says the control is unavailable, and WCAG exempts it. It must also flatten every variant identically: a disabled CTA that still glows amber is the loudest thing on a page that has nothing to press.

What this matrix caught. Disabled was painted from the surface-3 and text-4 tiers, which no dark scope re-points — so a disabled button on navy stayed a pale grey block. It takes --lw-bg-muted / --lw-fg-faint now. Six variants on one ground never showed it; the same six on both grounds showed it immediately.

variant="cta" is the amber, and the lint fails a view with more than one. It appears twice here because a specimen is not a view.
