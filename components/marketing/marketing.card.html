Marketing composites

StoryCard will not render a half-filled testimonial. The quote block appears only when quote, person and role are all present — checked at runtime, not documented in a file nobody reads. A quote with no attributable person is an invented one, and the component refuses to help.

One amber CTA per view. The hero below spends it; every other action on the page is cyan or ghost. That is the only rule that keeps a call to action meaning anything.

why it is built this way

Logo rail

Rail items are real anchors: pointer cursor, a lift and full-opacity brand ink on hover and focus, and a rail that dims its other marks while one is hovered — so the wall reads as a set being scanned rather than several logos shouting at once. Resting ink is a theme-aware token, never a hard-coded opacity, which would stay dark on a dark page.

The marquee variant fades at both edges with a mask rather than a gradient overlay, so it works on any ground, and it pauses on hover — a moving logo you cannot click is a reasonable thing to be annoyed by. Reduced motion falls back to the static wrap with no mask. The mark shown is LeanWise's own mono mark standing in for customer artwork.

Feature grid

A cell that looks clickable must behave like it is. .lw-feature-interactive carries a pointer cursor, a surface tint, the wipe-in rule, an arrow that advances 3px, and a :focus-visible ring — hover and focus are the same treatment, so a keyboard user sees what a mouse user sees. All of it stands down under prefers-reduced-motion.

Role tokens, not palette tiers. The index reads --lw-brand-text and the rules --lw-brand-line, both theme-aware — which is why the dark grid above needs no per-element overrides, only the .lw-band-dark scope. A numbered tier like brand-50 does not re-point, and would stay a light tint on a dark page.

Story card

Anatomy. The shipped .lw-story parts: a brand-line spine on the quote, a mono cite, and the outcome promoted to .lw-story-result — amber soft tint behind the amber text tier (:1), both of which re-point on dark.

Both halves of that pair must re-point together — a dark -on text tier left on a light tint measures 1.75 and disappears. In the React component the block renders only when quote, person and role are all present — the no-fabrication rule, enforced at runtime rather than in review.
