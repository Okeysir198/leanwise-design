Pricing

The word “pricing” appeared nowhere in this package, so every consumer wrote its own. The one that prompted this had .lw-price.featured restating five child colours to make one plan dark. .lw-plan composes .lw-card and adds four declarations; a dark featured plan is data-band="dark" and nothing else.

why it is built this way

A plan with no price is COMPLETE, not pending

The third card above publishes no price, no currency and no range — and it does not have a gap where one would go. Nothing in the CSS reserves the slot: no min-block-size, no placeholder, no content: "—". .lw-plan is a flex column with a gap, so the card simply closes up. This is the reason the component exists rather than living in the consumer: the primary consumer publishes no price, and a component that reserved the slot would force it to invent one. An invented price is a fabrication, which is the failure mode that codebase keeps relapsing into.

Featured adds an edge, never a ground

The second card is featured: a brand border and --lw-brand-glow, and that is the whole rule. It does not paint itself navy. The fourth card is the same component with data-band="dark" — zero child overrides, because the band re-points every role token on the element. That is the deleted override pile, shown.

Two glyphs and a word, never one colour

An excluded feature carries a minus, not a greyed check, plus an .lw-sr-only word that leads the row. Three signals, so the state survives a monochrome print, a colour-blind reader and a screen reader. The glyphs are <Icon name>; a typed ✓ would be the same drawing a second time in the font, and would be announced as punctuation. Same contract in the matrix below — and note the matrix uses --lw-success-on, not --lw-success, which is a fill and fails AA as text.

Two things deliberately NOT shipped

There is no .lw-plans grid and no PlanGrid — the row above is <Grid min={280}>, which already auto-fits and stretches. And there is no billing toggle: a billing period is a two-way exclusive choice, which is Segmented. What ships instead is the composition — .lw-plans-head, an eyebrow, a Segmented and an optional savings pill, shown on its own above the matrix. .lw-theme-toggle was deleted for being exactly this kind of duplicate.

The featured column is bg-subtle, not brand-soft

A brand tint would read better and cost more than it looks. --lw-fg on --lw-brand-soft is a pair nothing in this system composes today, so it would enter the derived contrast manifest as a brand-new measurement in three scopes — light, .dark and media-dark — for a decorative tint. --lw-fg on --lw-bg-subtle is already asserted. The brand signal is carried by --lw-brand-line edges instead, which is a non-text 1.4.11 boundary rather than a text ground.
