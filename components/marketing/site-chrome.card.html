Site chrome

A sticky bar under a sticky announcement is what every consumer gets wrong. Both claim inset-block-start: 0, so the header scrolls up underneath the strip and its first line is eaten. .lw-announce + .lw-topbar offsets the header by var(--lw-announce-h, 36px) — a contract that can only be written here, because .lw-topbar is ours. A consumer hand-rolling the strip cannot reach into the package's header to offset it, so it re-declares the header instead and inherits none of its later fixes.

why it is built this way

A dark footer is a BAND, not a navy tier

The second footer above sets one attribute: data-band="dark". It paints no navy, and not one child carries a dark variant. The band re-points every role token on the element — --lw-brand-text becomes brand-400, the inks become the dark tiers, the hairlines follow. The consumer this replaces hard-coded --lw-navy-900 and then restated five child inks on top of it; the one it got wrong was the mono column heading — brand-500 at 11px on navy — which failed AA on every page, in both locales.

The current page is not a colour

“Resources” is marked current in the light footer. It takes an ink lift, a weight step and a brand rule down its start edge — three signals, so the state survives a monochrome print, a colour-blind reader and a low-contrast screen. It is deliberately not a ▸: a typed glyph is an icon drawn a second time in the font, and screen readers announce it. Every link reserves the rule as a transparent border, so marking the current page shifts nothing.

A note is not a link

“SOC 2 — in progress” carries no href, so it renders as .lw-footer-note: a span, no pointer, no tab stop. It is deliberately absent from the consolidated pointer-affordance list, because a pointer over text that does nothing is a lie. The external entries name an icon instead of typing ↗.

Nothing new to compose with

The long disclaimer is .lw-measure; the social row is .lw-cluster + .lw-icon-btn. Neither got a class of its own — both already exist, and a footer-specific copy of either is how one system grows two treatments of one drawing.
